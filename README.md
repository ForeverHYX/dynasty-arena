# 天命争鼎 · 八帝同世

> 秦始皇、汉高祖、光武帝、隋文帝、唐高祖、宋太祖、元世祖、明太祖——中国八大开国皇帝同世而立，各据一州，逐月推演，争天下归属。
>
> **已推演完毕**：13 年 156 个月，617 条事件，终局「划河划岭 · 两帝一藩」——唐（李建成·李世民真共治）十州封禅泰山为天下主，东汉（刘庄）守河北续汉祀，残明（李文忠摄政护幼主）岭南藩属存明祀。秦、隋、西汉、宋、元相继而亡；八帝中唯有李建成活着看到"天下底定"。

**多智能体沙盘推演**：8 个势力代理分别扮演八朝开国君臣（人设、幕僚、战略思想、性格弱点均依史实设定），每 12 个月提交一轮方略；「天道」裁定代理对撞战争/外交/天灾/寿命/继承，产出正典编年；史官代理撰写终局评赞。

## 规则要点

- 十二州版图（省份归组）、相近的起始兵力粮草
- 战力 = 兵力 × 主将帅才 × 士气 × 兵种修正 × 粮秣
- 君主按历史享年做寿命判定（沙丘之变、烛影斧声等剧情依概率重演）
- 天灾人祸每阶段掷骰；继承人表决定身后事
- 终局：一统 / 稳定格局 / 120 月上限
