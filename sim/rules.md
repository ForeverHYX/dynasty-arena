# 天道裁定规则 · 数据格式

## 一、战力计算（天道裁定的依据）
- 进攻力 = 出动兵力 × 主将帅才系数(0.7~1.2, 见各人设) × 士气系数(0.6~1.1, 民心80→1.0) × 兵种修正 × 粮秣系数(断粮0.6)
- 防御力 = 守军 × 守将系数 × (1 + 地形加成[险塞0.4/水网0.25/平原0]) × 守土民心
- 兵种修正示例：骑战（平原+50%，漠北+50%）、水战（水网+40%）、攻城（械具+20%，无具-20%）、特殊：未修栈道出蜀-30%
- 胜负分级：惨胜/小胜/大胜/歼灭；伤亡 15%~45%；**州易手需「大胜」或守方内乱**，小胜仅推进/夺粮。
- 奇谋（伏兵、反间、夜袭、水攻等）由天道结合双方主将谋略酌定，允许冷门但须写明因果。

## 二、国力运转（每月）
- 军耗：粮 -兵力×0.5 万石；钱粮产出 = 领州粮产之和（隋 +15%，明屯田 +20%）。
- 粮尽：士气每月 -20，逃兵 5%；可「就食于敌」（入侵抢粮，所州民心 -10）。
- 征兵：每州每月可补兵 = 人口×0.01 万（隋府兵 ×1.25）；民心低于 50 减半。
- 稳定 < 40：每月 30% 概率民变/叛乱；< 25：宫变风险（可致君主死亡）。
- 州易手当年，该州产出与征兵打七折（人心未附）。

## 三、外交与背信
- 外交须双方意图匹配方成立（会盟/互不侵犯/借道/联姻/称臣/贸易）。
- 背盟者：民心 -5，其他势力下阶段「合纵防你」倾向大增；史官必书。
- 反间计：谋士（长孙晟、陈平之流）可离间他势力君臣/盟好，效果由天道酌定。

## 四、人物生死、寿命与继承（尽可能接近现实）
- **年龄表**（架空元年时的年龄 / 历史享年，供健康判定）：嬴政 45/49、刘邦 50/61、刘秀 35/62、杨坚 50/64、李渊 55/69、赵匡胤 45/50、忽必烈 55/79、朱元璋 45/71。重臣亦按历史生年推算年龄（王翦已老、常遇春青壮等）。
- 每阶段结束，天道对各君主做健康判定：年龄每 +1 岁；饮酒/亲征劳顿/重伤/丧子/国乱等加重；**年过 55 岁每阶段病故风险累积上升**；接近历史享年者风险陡增（历史上暴毙者——赵匡胤式——可在无铺垫下突然病死，这正是天意）。病故即病故，天道不得回避。
- 重臣可战死/病老而卒/被诛/被俘/叛逃，年迈重臣（60+）每阶段亦有自然减员可能（王翦、李善长式的老臣凋零）。
- **继承**：各家继承人现状见下表。君主死→继承人接位：稳定 -25、士气 -10，方略按新君性格重写。幼主（<16 岁）继位→「主少国疑」：稳定额外 -10，由摄政者（人设指定：吕后/独孤后/太后/权臣）实际掌权；无继承人→诸子/诸将争位内乱（稳定 -30 起）。
- **生育与开枝**：青壮君主每 24 个月可能新得子嗣（天道酌定），可改善继承线；子嗣成年（16 岁）后成为合格继承人。后宫事件（立储、嫡庶之争）依人设钩子演绎。
- 继承人表：秦=扶苏(约25,戍边/胡亥 18 暗线)；汉=刘盈(约10,幼主,吕后摄政)；东汉=刘庄(约5,幼主,阴郭之争定摄政)；隋=杨勇(约30)/杨广(约28,夺嫡引信)；唐=李建成(约30)/李世民(约27,家务事即继承战)；宋=赵匡义(约30,弟)/赵德昭(约14,幼)；元=真金太子(约25,汉法派)；明=朱标(约25,仁厚)。
- 各势力人设中的「剧情钩子」条件满足时，天道**必须**演绎。

## 四之二、天灾人祸（每阶段必掷）
- 天道每阶段掷 1~2 次天灾/人祸（旱、涝、蝗、震、瘟疫、黄河决口、草原白灾、边寇流窜），目标州由天道酌定（人口稠密/低稳定处优先）。效果：该州当年粮产 -20%~50%、民心/稳定 -5~-15；瘟疫可折兵；白灾重创漠北（元势力的天敌）。
- 天灾可与人事联动：救灾得民心（仁君人设加分），救灾不力→民变概率大增；「伐无道」者可借灾煽动。
- 天灾事件同样入 canonical（type=economy 或 crisis），白话战报风格。

## 五、天道平衡（防流水账）
- 天道无情，不偏爱：一切依数值与因果裁定。
- 树大招风：扩张最盛的势力必遭反噬——两线作战/盟友反目/民变四起，任天道择之。
- 每个势力每阶段至少一次可书之挫败或内部危机。
- 君主亲征：战败则士气 -15、稳定 -10；刘邦亲征帅才仅 0.8（自将屡败），忽必烈 0.95，嬴政居中不亲征，李世民为帅时唐军战力上限另加 10%。

## 六、事件文风（游戏情报风，非史书体）
- title：短促有力的游戏事件标题（≤12 字），如「秦军叩关」「陈仓栈道成」「杯酒释兵权」「伯颜围洛阳」。
- desc：**现代白话**，信息密度高：谁、在哪里、干了什么、结果如何、影响什么数值；50~80 字；可直接读出因果，不用文言句式、不写「曰」「矣」「之」。可以有少量人物台词或心理作为点缀（引号内）。
- 事件是要显示在游戏界面上给玩家看的「战报/新闻推送」，想象文明系列的事件弹窗与新闻条。
- 各势力意图文件（附录A）里的 detail/wishes/strategy 同样用白话。

## 六之一、势力交互（铁律）
- 八国共存一世，**任何势力方略必须对他国的战争、外交、背盟做出反应**：他国来攻必应战或求和；邻国相争必考虑渔利或救援；盟约必有人履约或背弃。天道裁定时应优先演绎**跨势力冲突与合纵连横**，纯内政月过多则天下失味。
- 外交匹配制：会盟/互不侵犯/借道/联姻须双方意图对应方生效；单方面宣布无效，天道不书。
- 天道每阶段至少裁定一次**两国以上卷入的多方事件**（三方会战、围魏救赵、两线夹击、连横伐一、反间破盟等），写出全局联动。

## 七、终局判定（循环结束条件）
推演以 12 个月为一阶段循环，直至达成以下任一：
1. **一统**：一方尽收十二州，或其余势力尽数灭亡（州皆归一主）。
2. **稳定格局**：连续 12 个月无州易手、无国战，且现存诸势力稳定均 ≥ 55——大势已定，对峙集团成形（如划江而治、三足鼎立）。天道在该阶段末月书「天下底定」事件宣告终局。
3. 硬上限：至第 120 月（十年）强制收官，以当时州数最多者与格局论之。
每阶段裁定末，天道须在回复中声明是否达成终局。

## 附录A：势力意图文件 schema（arcs/phase{N}-{fid}.json）
```json
{
  "faction": "qin",
  "phase": 1,
  "strategy": "本阶段总方略，≤100字",
  "months": {
    "1": [
      {"kind": "battle|move|diplo|internal|build|spy|wait",
       "target": "州id或势力id或null",
       "troops": 10,
       "general": "主将姓名或null",
       "detail": "≤60字方略：路线/诡道/协同/政令内容",
       "wishes": "若得手的一句预期"}
    ],
    "2": [],
    "...": "绝对月份为键：第一阶段1..12，第二阶段13..24，第三阶段25..36；每月1~2个行动"
  },
  "diplomacy": [
    {"to": "sui", "proposal": "会盟|互不侵犯|借道|联姻|称臣|贸易|警告", "terms": "条件一句话"}
  ],
  "self_note": "内部隐情≤50字，不为他势力所知"
}
```
- battle：攻州或向他势力野战主力会战；必须写 troops（万）与 general。
- move：移防/驻屯/撤退；internal：政令、人事、民生、清洗；build：筑城/造船/修栈道/储粮/练兵/铸炮；spy：谍报/反间/行间。

## 附录B：天道正典文件 schema（canonical/phase{N}.json）
```json
{
  "phase": 1,
  "events": [
    {
      "month": 1,
      "type": "war|politics|internal|diplomacy|economy|crisis|character",
      "faction": "qin|han|donghan|sui|tang|song|yuan|ming|neutral",
      "region": "州id或null",
      "title": "≤12字游戏事件标题",
      "desc": "50~80字白话战报(谁/哪里/干了什么/结果/影响)",
      "actors": ["嬴政", "王翦"],
      "inter": true,
      "delta": {
        "troops":    {"qin": -2.0, "sui": -4.5},
        "food":      {"qin": -3},
        "morale":    {"qin": 3, "sui": -6},
        "stability": {"sui": -4},
        "regions":   {"guanzhong": "qin"},
        "characters": [{"name": "某将", "faction": "sui", "status": "战死|被俘|叛逃|病故|被诛|起复"}]
      }
    }
  ]
}
```
delta 中只写有变化的键；regions 只在实际易手时写。`inter` 标记是否为跨势力交互事件（战争/会盟/背盟/称臣/多国博弈），界面将以此高亮「交锋」事件；纯内政写 false。

## 附录C：天下状态文件 schema（state-phase{N}.json）

```json
{
  "month": 12,
  "factions": {
    "qin": {"name":"秦","leader":"嬴政","troops":16.5,"food":15,"morale":78,"stability":80,

```
（regions 每州都列；中立州 owner 为 "neutral"，garrison 为剩余守军。）
