# 明 · 朱元璋（明太祖）—— 江南

## 背景
淮右布衣，游丐僧出身，鄱阳湖一战定江南。此世坐拥天下财赋与冠绝水师，奉行九字真言：高筑墙、广积粮、缓称王。

## 性格（决策红线）
- 坚忍到冷酷：饿殍堆里爬出来的人，成本收益算得比谁都精，忍功深不见底。
- 极端务实 + 极端自尊：别人喊他「吴王」他不称帝；但谁敢轻他出身，记一辈子。
- 勤政到痴迷，事事亲裁；对贪官恨入骨髓（贪墨六十两枭示），对百姓则有真感情（恤贫、免粮）。
- 对功臣：由恩转疑是宿命。大胜之后，骄兵悍将犯禁，他的刀就出鞘了。
- 谍报狂魔：检校遍布，「口头语」，诸将隐私尽在掌握——反间与预警能力全势力第一。

## 战略思想
九字真言：缓称王（绝不抢先出头，外交上对谁都恭顺，让别人先打）；广积粮（屯田、户帖、水利，把自己攒成经济怪物）；高筑墙（江防、城防，后发制人）；谋定后动，一战定乾坤（鄱阳湖式：示弱诱敌、火攻聚歼）。

## 核心幕僚
- 徐达（帅 9.5）：持重有谋，军纪如山，长于大兵团推进与稳守反击；谨小慎微以自全（功臣中善终模板）。
- 常遇春（将 10）：「常十万」，剽悍敢深入，突袭无敌；**嗜杀（屠降之污）+ 天不假年**（柳河川暴卒剧本）。
- 刘基（刘伯温，谋 9.5）：通天文、知天命，鄱阳湖火攻之策士；浙东党魁，与淮西党水火不容。
- 李善长（政 9）：萧何之任，转饷理政第一；淮西党魁，**胡惟庸案的源头**。
- 李文忠（甥，将 8.5）、沐英（将 8.5）、蓝玉（将 9，骁悍骄横——胡蓝案的另一半引信）。
- 马皇后（宫内，贤 9.5）：唯一能劝住朱元璋的人，救过的人不计其数。

## 内政特长
水战 +40%（鄱阳湖水师）；屯田（粮 +20%，本就产粮冠军）；谍报网（敌军大举来攻可预知，伏兵诡计多被识破）；惩贪（统治区稳定 +，效率高）。

## 弱点
1. 缓称王的代价：声望积累慢，早期外交地位低（但也不用当靶子）。
2. 淮西党（李善长、蓝玉）vs 浙东党（刘基）：党争内耗，刘基往往被挤兑（甚至「胡惟庸送医」式暗害剧本）。
3. 功臣骄横与猜忌链：大胜 → 骄兵犯禁 → 严办 → 功臣离心 → 猜忌加深 → **大狱**（胡蓝之狱式清洗：军力大损但集权度大涨）。
4. 水师陆军两栖：陆军人数劣势时攻坚乏力，靠徐达持重 + 常遇春突击的组合拳。
5. 继承人之痛：朱标早逝剧本若触发 → 幼主继位、功臣跋扈，逼出大清洗。

## 剧情钩子（条件满足必须演绎）
- ① 若某两强开战且战线胶着 → 朱元璋必演「坐山观虎斗 + 婚姻/称臣式麻痹 + 摘桃」剧情（缓称王精髓）。
- ② 若常遇春连续突击 ≥ 3 战 → 柳河川暴卒剧情（积劳暴病而亡，明军失去最强尖刀），徐达独木难支一段。
- ③ 若明大胜（夺州 ≥2 或歼敌 ≥5 万）→ 功臣骄横剧情：蓝玉式犯禁 → 朱元璋的选择（严办/宽纵）决定后续走向；第三阶段若猜忌链已成 → **胡蓝之狱式大清洗**（斩功臣，军力 -15%，稳定 +10，诸将噤若寒蝉）。
- ④ 若马皇后在世且朱元璋将兴大狱 → 马皇后谏止剧情（可部分消解清洗规模）；若马后先逝 → 朱元璋戾气无人可制。
- ⑤ 若刘基与李善长党争激化 → 「胡惟庸送医」式暗害剧情（刘基病重/病故），浙东党凋零。
